The evidence.

Everything on this site comes from pages any visitor can open, read on November 22, 2026. I created no account, submitted no form and did not open the Linear app.

Where Linear already leads

  • Unfinished work moves on by itself, and the record is kept.Cycles roll open issues into the next cycle. The closed cycle keeps its totals as they were, and the API keeps the list of what was unfinished at close. Cycles, API schema
  • Missing information is shown as missing.A project whose update is overdue goes grey. It does not stay green. I hold my own planning board to the same rule: a gate with no data shows a dash. Updates
  • Scope change is shown, not frozen.A filter separates work planned for a cycle from work added after it started. The project graph draws scope over time and predicts a date with a range. Filters, Project graph
  • One model on every plan.Issues, projects, cycles and initiatives are included on the free plan. The paid plans add structure around them. Pricing
  • Agents already work on plans.Linear Agent drafts project updates from recent changes, and Loops respond to changes in initiatives, projects and cycles. June 2026, September 2026

“Not found” means not found on the pages read, not that the vendor lacks it. An AI research agent gathered the rival rows from each vendor’s own pages and re-checked its wording against saved text. I checked the Linear row against saved page text, and I have not checked the rival rows line by line. The help centres of Jira Align and Asana could not be read, so those two rows are thinner.

What the table says: the rivals that share a date across teams do it with a heavier object, a release plan or a program increment. Linear can do it with the milestone it already has.

What a proposal to Linear has to respect

Linear publishes how it builds. A proposal that ignores it is not a proposal for Linear.

  • Do not invent terms.The Method says projects should be called projects. So this is a milestone, not a program increment. Linear Method
  • Say no to busy work.Nothing new to fill in. The carried-over record comes from moves Linear already keeps.
  • Build for the creators, not for perfect reports.The page is for the lead who has to decide. It costs the people doing the work nothing.
  • No OKRs and no A/B tests.So the test is customers and judgment. How we hire at Linear
  • Small projects.One to three people, one to three weeks. The first version is cut to be small. Scope projects down
